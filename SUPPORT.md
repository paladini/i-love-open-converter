# Support

For usage questions, search existing reports and open a [GitHub issue labeled question](https://github.com/paladini/i-love-open-converter/issues/new?labels=question). GitHub Discussions are not enabled for this repository.

For a reproducible bug, include:

- App version or container image tag and deployment profile.
- Host operating system and architecture, Docker Engine and Compose versions, and browser.
- The operation and sanitized steps that reproduce the problem.
- Relevant sanitized logs and the resulting error code.

Do not upload private documents, personal data, passwords, tokens, or other secrets. Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md), never in a public issue. There is no response-time guarantee.
