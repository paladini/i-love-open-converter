# Contributor Covenant Code of Conduct

## Our pledge

We are committed to making participation in I Love Open Converter welcoming and respectful to everyone, regardless of background, identity, experience, or viewpoint.

## Expected behavior

- Be respectful, constructive, and considerate.
- Accept differing viewpoints and give feedback about ideas, not people.
- Respect privacy. Do not publish other people's personal information, private documents, credentials, or security reports.
- Keep project spaces focused on the project.

## Unacceptable behavior

Harassment, discrimination, intimidation, personal attacks, unwanted sexual attention, doxxing, and publishing private information or security details without consent are not acceptable.

## Enforcement

For conduct involving a GitHub issue, pull request, comment, or account, use GitHub's **Report content** or **Report abuse** action. If GitHub offers **Report to repository admins**, that routes the report privately to the maintainers; otherwise use **Report abuse to GitHub Support**. For other conduct concerns, use GitHub's [abuse reporting form](https://support.github.com/contact/report-abuse). Do not post private documents or security-sensitive details in a public issue. Maintainers may remove content, restrict participation, or block accounts when needed to protect the community. No response-time guarantee is offered.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
