HTML para PDF

Converta um arquivo HTML local. Estilos incorporados e imagens data URI são aceitos; referências a arquivos locais ou URLs externas são bloqueadas.

Origem da página

HTML local aceita estilos incorporados e data URI. Ao escolher uma URL, o serviço web do seu servidor acessa a página pública e incorpora recursos estáticos com limites; endereços privados são bloqueados. O host precisa de saída direta nas portas 80/443. O worker Linux renderiza sem rede; JavaScript e páginas com login não são suportados.
