# Project state

## Decisions

| ID | Decision | Rationale | Status | Date |
| --- | --- | --- | --- | --- |
| AD-001 | The application has no user authentication; anyone who can reach the self-hosted service may use it | The user explicitly requested a free, unauthenticated HomeLab/local service | active | 2026-11-19 |
| AD-002 | License the project under AGPL-3.0 | The user selected AGPL-3.0 to keep network-served modifications open | active | 2026-11-19 |
| AD-003 | Store conversion jobs in SQLite and input/output files on the local shared volume; a separate worker polls SQLite | Lightweight single-host deployment avoids a separate broker and external storage, matching the HomeLab target | active | 2026-11-19 |
| AD-004 | Use `pymupdf-lite` for the basic PDF toolchain | It retains the PyMuPDF API and AGPL path while omitting optional layout/OCR model dependencies from the base container, reducing image size and keeping basic operations local | superseded by AD-013 | 2026-11-19 |
| AD-005 | Enforce upload count, per-file bytes, and aggregate file bytes inside the streaming multipart parser | Limits must stop excess data before it is written to temporary upload files; this bounds the unauthenticated service's upload-spool exposure | active | 2026-11-19 |
| AD-006 | Mirror the ILovePDF/ILoveIMG tool-catalog and upload-first workflow while retaining the I Love Open Converter brand and fully local, free operation | The user asked for a copy of both products while the original request requires self-hosting, no ads, no telemetry and no third-party file transfer; use the same categories, card hierarchy, clear operation pages and prominent local upload, but omit source trademarks, cloud imports, login and paid tiers | active | 2026-11-19 |
| AD-007 | Keep the full named PDF and image catalog visible across roadmap stages; disable tools not yet shipped and label them “Em breve” / “Coming soon” | Catalog coverage should not imply that future-stage operations already work | active | 2026-11-19 |
| AD-008 | For password-protected PDF jobs, pass the password in a separate multipart field and keep it temporarily in a per-job file on the shared local volume, created with mode 0600 where supported; delete it after terminal processing | Web and worker are separate processes and interrupted jobs need the secret to be retried; passwords must not enter job options or logs. A crash can leave the temporary file until the job is retried or expires. | active | 2026-11-19 |
| AD-009 | PDF/A conversion targets PDF/A-2b using local Ghostscript with base fonts and an sRGB profile, then checks each result with the pinned veraPDF CLI 1.30.3; fail closed on conversion or validation errors | A local spike showed that PDF/A validation alone can pass a blank output if the converter silently loses content. Stop on PDF errors and additionally compare page count and extracted text. The runtime image includes Ghostscript and Java for this feature. | active | 2026-11-19 |
| AD-010 | Reject redaction jobs for PDFs with tagged or marked content and accessibility text until those structures can be sanitized safely | Review reproduced recoverable `/ActualText` after graphical redaction. Failing closed avoids delivering a misleading result; the UI and documentation explain this restriction. | active | 2026-11-20 |
| AD-011 | Use pinned `pypdf==7.1.1` alongside PyMuPDF to read image drawing order and indirect object identities from PDF content streams | PyMuPDF's image-info xref lookup uses image digests and can conflate distinct objects with identical pixels; preserving distinct objects and ordering requires reading drawing operations. PyMuPDF remains the image decoder. | active | 2026-11-20 |
| AD-012 | Run LibreOffice conversions only in a network-isolated Linux worker with an individual Landlock filesystem policy, temporary profile and no trusted macro locations | Office documents can trigger external resources or macros and the worker shares a volume containing other jobs. Fail closed when the required isolation is unavailable. | active | 2026-11-20 |
| AD-013 | Replace `pymupdf-lite` with pinned full `pymupdf==2.1` when shipping PDF-to-Markdown | The lite package exposes but does not implement `to_markdown`; full PyMuPDF provides local layout and Markdown conversion. Validate both supported Linux architectures and retain the offline worker. | active | 2026-11-20 |
| AD-014 | Use pinned `pdf2docx==0.5.13` for editable PDF-to-Word conversion in a bounded subprocess | Its published MIT release worked with PyMuPDF 2.1 in a local probe. Upstream is no longer actively maintained, so document that status and validate compatibility and output on supported architectures. | active | 2026-11-20 |
| AD-015 | Convert PDF-to-Excel data locally by extracting detected tables and non-table text into XLSX worksheets; preserve all source values as literal strings and disable formula/URL interpretation | PDF layouts do not reliably expose typed data. Literal text preserves identifiers and prevents formula injection; detected tables and text remain editable cells with source page references. Keep OCR separate. | active | 2026-11-21 |
| AD-016 | Ship the first photo-editor stage with text, local filters, and frames; defer stickers to a later editor stage | The user selected a simple local editor and kept stickers for a separate stage, avoiding extra controls in the first release. | active | 2026-11-21 |
| AD-017 | Use the versioned Argos PT-BR/English model archives with CTranslate2 and SentencePiece directly for offline PDF translation; do not install Argos Translate's Stanza/PyTorch dependency chain | The user approved about 200 MB of image growth. The official PyPI Argos Translate 1.11.0 graph includes Stanza and a Linux PyTorch wheel over 500 MB; direct CTranslate2 inference keeps the same model files and local behavior close to the approved size. | active | 2026-11-21 |
| AD-018 | Offer separate local image privacy tools: automatic plate blur using bundled OpenCV classifiers, and arbitrary-object blur through user-drawn rectangles on an image preview | The user approved “placas automáticas + objetos por seleção manual”; document that plate detection can miss results and manual regions only cover what the visitor selects. | active | 2026-11-21 |
| AD-019 | Convert SVG to bounded PNG, JPEG or WebP locally through the existing isolated WeasyPrint worker; reject scripts, animation, foreign content and external resources | Advances the user-approved format-conversion roadmap while keeping SVG parsing isolated and preventing network or host-file access. | active | 2026-11-21 |
