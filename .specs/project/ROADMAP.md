# Project Roadmap

## Completed Milestones

- [x] **M1: Foundation & Local Queue** — FastAPI web app, SQLite job queue, streaming upload limits, Docker Compose runtime.
- [x] **M2: Core PDF & Image Suite** — Merge, split, rotate, compress, PDF/JPG conversions, watermarks, page numbers, crop, resize, meme generator, photo editor.
- [x] **M3: Advanced Document & Privacy Tools** — Office-to-PDF, PDF-to-Word/Excel/PowerPoint/Markdown, HTML/URL rendering, SVG/PSD/HEIC/RAW decoders, OCR, local AI summary & translation, PDF forms, redaction, face/plate/object blur.
- [x] **M4: iLovePDF & iLoveIMG Studio UX Overhaul (`ui-ilovepdf-experience`)** — Domain-adaptive OKLCH design system, 2-column Studio Workspace, visual file cards with thumbnails/sheet previews, bespoke SVG catalog icons, instant tool search, and unified navigation across all 19 templates.
