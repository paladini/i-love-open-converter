# I Love Open Converter — Project Vision

## Vision

Provide a fast, self-hosted, 100% private alternative to **iLovePDF** and **iLoveIMG** for HomeLabs and teams—delivering 50 PDF, image, Office, and HTML tools with zero ads, zero trackers, and zero cloud file uploads under the AGPL-3.0 license.

## Core Pillars

1. **100% Local & Self-Hosted:** Every file stays on the server controlled by the user.
2. **Familiar Studio Ergonomics:** Domain-coded visual language (iLovePDF Crimson Coral for PDFs, iLoveIMG Cobalt Indigo for Images), upload-first dropzones, visual file cards with live previews, and focused options sidebars.
3. **Bilingual by Default:** Complete English (`en`) and Brazilian Portuguese (`pt-BR`) localization across all 50 tools.
4. **Defense-in-Depth Isolation:** Streaming upload limits, format validation, and isolated subprocess workers for untrusted inputs.
