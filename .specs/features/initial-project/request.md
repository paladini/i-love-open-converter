\## Visão do produto\
\
I Love Open Converter deve ser uma aplicação self-hosted com interface gráfica web, bonita, leve e extremamente fácil de usar. Seu objetivo é permitir que qualquer pessoa faça conversões de qualquer arquivo para qualquer outro tipo de arquivo, com funcionalidades muito similares e inspiração forte no funcionamento do ILovePDF e ILoveIMG:
[https://www.ilovepdf.com/pt](https://www.ilovepdf.com/pt)
[https://www.iloveimg.com/pt](https://www.iloveimg.com/pt)\
\
A experiência deve ser simples para quem nunca ouviu falar em modelos de IA, programas e dependências Python ou Linux para realizar conversões e operações sobre esses arquivos. O usuário deve poder escolher um arquivo qualquer (PDF ou Imagem), escolher a operação que deseja fazer nesse arquivo, iniciar o processamento, ver o resultado e baixar os arquivos.\
\
O projeto deve usar como principal motor de processamento bibliotecas open-source do Python e outros pacotes comumente disponíveis no Docker e em sistemas operacionais Self-Hosted e HomeLab. Procure as melhores, mais estáveis e robustas bibliotecas para fazer os tipos de conversões e operações disponíveis no ILovePDF e ILoveIMG. A ideia é fornecer tudo isso gratuitamente para usuários, e que eles possam fazer self-host dessa versão open-source extremamente completa, sem anúncios ou telemetria enviando dados pra fora.&#x20;
